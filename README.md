# IT Analyst Portfolio Website

A responsive static portfolio starter tailored to an IT support professional moving toward IT Operations, ITSM/ServiceNow, and reporting/analyst roles.

## Before publishing
1. Replace `Your Name` and `YN` in `index.html` with your preferred professional name/initials.
2. Update the About section to match your exact experience.
3. Replace generic LinkedIn and GitHub links with your own profile URLs.
4. Keep project statuses accurate. The sample projects are marked Planned; only change them after you complete the work.
5. Add project repository links and screenshots as you finish projects. Use only fictional/public data and never publish confidential employer or customer information.
6. Review all skills labels and change them to reflect what you can confidently discuss in an interview.

## Preview locally
Open `index.html` in a browser. The website uses a Google Fonts import; if you are offline, it will fall back to system fonts.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a public repository named `YOUR-USERNAME.github.io`.
3. Upload `index.html`, `styles.css`, and this README (the README is optional for the site itself).
4. In repository Settings, open Pages and configure publishing from the main branch/root if prompted.
5. Wait for the deployment and visit `https://YOUR-USERNAME.github.io`.

GitHub Pages official guide: https://docs.github.com/en/pages/quickstart

## Recommended first project
Build the IT Service Desk Analytics Dashboard using a fictional dataset of 300–500 tickets. Include a cleaned CSV, a Power BI dashboard, a README describing the business question and methods, and a one-page insight summary. Link the completed project from this portfolio only after the deliverables exist.
